# ProcessBar with Sine / 带正弦波浪的进度条

An enhanced Flutter progress bar library following Material Design 3, featuring dynamic sine-wave animations. It offers deep customization for thumb shapes and track styles, delivering a fluid and personalized interactive experience.

一个遵循 Material Design 3 标准的增强版 Flutter 进度条库，支持动态正弦波浪动画。它允许高度自定义滑块形状与轨道样式，为应用提供灵动且极具个性的交互体验。
